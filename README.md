# TenantFlex website

The public website for **TenantFlex**: tenancy, billing and payments for business and shopping complexes.

- `index.html`: product showcase (tenant app, manager app, payments, billing automation, communication, platforms, FAQ)
- `features.html`: every screen of both apps
- `pricing.html`: management subscription rates, billed monthly or annually (prices are set in one place in the page generator)
- `demo.html`, `demo/tenant/`, `demo/manager/`: live demos of the tenant app and the management app. They're the real apps and API running in the browser on PGlite, built from the TenantFlex repo with `npm run build:demo -w web` (copy `web/dist/tenant-demo` → `demo/tenant`, `web/dist/manager-demo` → `demo/manager`)
- `privacy.html`, `terms.html`, `data-processing.html`, `delete-account.html`: legal pages (Kenya Data Protection Act, 2019); text lives in `tools/legal_content.py`
- `contact.html`: contact details (WhatsApp +254 747 354 677, info@pizzatechnologies.co.ke) and the onboarding steps

The HTML pages are generated by `python3 tools/build_site.py` (edit that file or `tools/legal_content.py`, then re-run it); the result is a static site with no server. Preview it locally with `python3 -m http.server` and open http://localhost:8000.

## Publishing with GitHub Pages
Settings → Pages → *Build and deployment* → Source: **Deploy from a branch** → Branch: **gh-pages** / **(root)** → Save.
The site is then served at `https://pizzatechies.github.io/flexhub/`.

Screenshots in `assets/img/` were taken from the real TenantFlex apps using the Golden Gate Plaza demo complex.
