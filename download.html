Installing on Android

Open the downloaded .apk. If Android asks, allow your browser to “install unknown apps”, then tap Install. These builds are installed directly rather than through Google Play.

Installing on Windows

Run the installer and choose where to install. The installers are not yet code-signed, so Windows SmartScreen may show “Windows protected your PC”. Click More info → Run anyway.

Setup guide

Up and running in minutes

Every complex runs a TenantFlex server, which holds your data and serves the apps. It can be an office PC, your own server or a cloud host.

  1. Start the TenantFlex server. It needs Node.js 22 and PostgreSQL. From the TenantFlex server package, run npm install, npm run build and npm start. The server creates its database tables automatically and listens on port 4000. A Docker Compose file is also included for cloud hosting.
  2. Open TenantFlex Manager and connect it. On the sign-in screen tap Server and enter your server's address, e.g. http://192.168.1.20:4000 on the office network or https://pay.yourcomplex.co.ke online.
  3. Register your complex. Choose Register complex and enter your details. KES is selected by default.
  4. Configure billing. In Settings, set the rent billing day, payment terms, electricity and water rates, and the bank account for transfers.
  5. Add units and invite tenants. Add your units, then share the invite code shown on the Tenants page. Tenants install TenantFlex, enter the same server address, and choose Join my complex.
  6. Bill and get paid. Run monthly rent or wait for the billing day, enter meter readings for utilities, and watch payments and receipts arrive.
For tenants to pay from anywhere, put the server on the internet over HTTPS, for example on a cloud server or behind a secure tunnel. On an office network only, apps must be connected to the same Wi-Fi.
